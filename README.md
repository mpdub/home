# Martin Wong homepage

A build-free homepage using the portfolio’s colours, typography and original interactive pig.

Contact details are copied from the current portfolio. The font is loaded from Google Fonts, with system-font fallbacks.

## Upload

Unzip and upload index.html, styles.css, site.js and assets/ to the root of your homepage repository. Keep any existing CNAME file and project folders. This package does not move or change the portfolio or other projects.

The homepage intentionally contains no project navigation. Share /work/, /vco/ and other project links separately once those projects are deployed.

## Checks

Local asset references and JavaScript syntax checked. Browser rendering has not been checked in this environment.
